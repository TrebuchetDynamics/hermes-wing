## Reference and result rules

Official reference: [Nous Research apps/desktop](https://github.com/NousResearch/hermes-agent/tree/158fd638da1629c8e62caf9ade1515d162def8ab/apps/desktop),
Agent commit `158fd638da1629c8e62caf9ade1515d162def8ab`, Desktop tree
`2038178ee53e13cde6fe297daa2484a868e7d3a3`.
This is the read-only local checkout, not latest main, a release, or an executed app.
Wing implementation inspected at `5c6ccdf3ea6b1df22aa3f797977fcc21fd690859`.
See [official authority](../quality/official-desktop-reference.md) and
[rebuild evidence/limits](../quality/official-feature-matrix-rebuild.md).

The retired separate-app mapping is withdrawn, not renamed onto this source.
No old source paths, candidate flows or parity totals were inherited. IDs are
retained only where the new source supports the same bounded topic. Legacy task
IDs, remaining-task associations, historical result values and receipt attribution
are preserved in JSON `historical_mappings`, including groups not admitted here.
They do not change task statuses, ownership, leases or historical checks.

- **supported**: the specifically described Wing source outcome exists; not a
  named-platform verdict or full-group parity claim.
- **unsupported**: the stated official outcome is absent/unavailable in Wing;
  testing its unavailable state cannot pass its positive acceptance.
- **unverified**: behavior, exact authority, completeness or matching qualification
  is not established. Implemented subsets are described without certifying the group.
- **Trace depth** is separate: registration/composition, bounded caller/helper,
  semantic action, or inspected test. A real source citation alone does not prove
  its entire controller, backend handler, native IPC or recovery contract.

Agent owns domain state. Desktop REST, JSON-RPC and Electron capabilities are
not interchangeable or automatically available to Wing. Use exact advertised
operations/grants and explicit connection/profile/Project/session identities.
Do not patch Agent, introduce a shell bridge, restore retired management, or
silently replay mutations to fill a parity gap. [Routes](routes.md) owns Wing
support wording; [ADR](../adr/product.md#official-desktop-features-only) owns admission.
