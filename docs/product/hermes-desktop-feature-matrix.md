This is a feature-group inventory, not exhaustive control coverage or 1:1 certification.

## Reference and result rules

Official reference: [Nous Research apps/desktop](https://github.com/NousResearch/hermes-agent/tree/a2ad0d5b639160fbb41b2bee8d1ca1e65e544c70/apps/desktop),
Agent commit `a2ad0d5b639160fbb41b2bee8d1ca1e65e544c70`, Desktop tree `cee4414aae0817b7ff45c76fbfd010dcd753ecf5`.
Wing source inspected at `d13b748a4d5b8d5a580f2e0735fbb08387cb2238`. The snapshot is not a
release, running app or assertion that upstream main has stopped advancing.
The permanent read-only Agent checkout was not updated. See the
[current refresh and accepted priority](../quality/official-desktop-parity-refresh-2026-10-18.md#scope-and-priority),
[official authority](../quality/official-desktop-reference.md) and historical
[rebuild evidence](../quality/official-feature-matrix-rebuild.md).

- **supported** means only a specifically bounded source outcome, never full-group parity.
- **unsupported** means the stated outcome is absent/unavailable in inspected Wing source.
- **unverified** includes partial implementations without complete semantic/contract proof.
- Trace depth is separate from positive support; inspected tests were not executed.
- All 90 inherited target cells are preserved; the five explicit subgroups add ten
  `not_run` cells. Old candidate paths remain leads, not qualification against this pin.

Agent owns domain state. Desktop REST, JSON-RPC and native IPC are not interchangeable
or automatically available in Wing. Require exact advertised operations/grants and
connection/profile/Project/session identities. No Agent patches, shell bridge,
shadow inventory or silent replay. [Routes](routes.md) owns support wording.
The retired separate-app mapping remains withdrawn; historical task/receipt
attribution in JSON is preserved, not promoted to current parity.
