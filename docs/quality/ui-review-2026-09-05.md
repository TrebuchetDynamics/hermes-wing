# UI review — 5 September 2026

This pass updates the shared Flutter theme across Hermes Wing: typography,
neutral surfaces, cards, fields, buttons, navigation, dialogs, and sheets.
Screen-specific corrections cover the compact chat header, provider status rows,
settings groups and theme selection, gateway headings, gateway pickers, and
scrollable empty states. Agent capability checks and the Agent/Wing Link
ownership boundary are unchanged.

## Reproduce the physical visual tour

Use an isolated QA package on an authorized connected Android device:

```bash
WING_ISOLATED_DEVICE_TEST=1 flutter build apk --debug \
  -t integration_test/hermes_features_maestro_main.dart
adb -s "$ANDROID_SERIAL" install -r build/app/outputs/flutter-apk/app-debug.apk
maestro --device "$ANDROID_SERIAL" test \
  --test-output-dir /tmp/hermes-wing-ui-review \
  scripts/maestro/fixture/visual_review.yaml
```

The tour captures Profiles, Tools, Office, Providers, Persona, Gateway, Settings,
Voice settings, Diagnostics, Schedules, Chat, Pairing, and Local setup in light
and dark themes. It asserts zero reported Flutter layout overflows at the end
of the dark-theme tour. The QA footer and fixture controls are test-only.
Screenshots belong outside Git and outside the shared Playwright `test-results`
directory, which other test runs may replace.

## Evidence and limits

The visual tour passed on a physical Samsung SM-S928B running Android 16,
producing 26 screenshots. The captures use deterministic public-example data;
they do not qualify live provider inference, real pairing, microphone behavior,
or an actual Termux installation. Tools intentionally shows its unavailable
inventory state because the fixture does not advertise that inventory.

Regression coverage includes primary-button contrast across every palette,
recovery actions at 200% text scale in a short viewport, and a 320-pixel chat
header with a long profile name and an operable profile switcher/session panel.
README and landing visuals were regenerated with `npm run readme:assets`.
