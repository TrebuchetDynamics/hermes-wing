One client, every screen

Stay attached to the work.

Wing keeps the active Hermes session close without pretending to be the agent. Hermes remains authoritative for runs, tools, profiles, approvals, and configuration.

A client, not a second control plane

Hermes stays in charge.

Wing connects through Hermes's HTTPS API and SSE event stream. It does not read Hermes files, duplicate agent state, or silently enable unsupported operations.

    Negotiate capability

  3. 03

    Stream authoritative state
