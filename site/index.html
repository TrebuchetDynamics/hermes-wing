Bring your own Agent

From connection to first reply.

  1. Open Wing on your chosen screen

    Build a native Android/Linux client, or open the web alpha. Expect Welcome to Hermes Wing; with an existing connection, use Add Hermes from Chat. Source builds do not install Agent. Browser SSH and OAuth sign-in are unsupported.

  2. Prepare a compatible authenticated API

    Enable the Agent HTTP API and configure a strong Agent access token. A working CLI alone is not enough. Wing reads /v1/capabilities (schema 1): exact session and streaming operations (runs SSE or session chat), required grants and profile context must match. Health or OpenAI-compatible chat alone is not Wing compatibility. Configure the selected profile, provider and model in Agent.

  3. Choose a trusted connection

    Native Linux Local uses a prepared loopback Agent; discovery does not start it. Android offers Connect via SSH, Connect to Remote Hermes, then Use this phone (Termux). SSH verifies the host fingerprint and still needs the separate Agent token. Same-phone installation is not fully verified. Follow your native route.

    Remote browsers need trusted HTTPS and CORS explicitly allowing the Wing website origin (for this hosted alpha, https://trebuchetdynamics.github.io). Loopback refers to the browser's device, not your Agent host. Use the browser guide; never disable certificate checks or open a public port to bypass setup.

  4. Connect deliberately, then send once

    Enter the approved endpoint and Agent token only in Wing's connection form, never on this page or in a URL. It is not your provider API key. Select the configured profile/conversation and model. Providers may charge and process conversation data. Send: “Reply with one sentence introducing yourself. Do not use any tools.”

    First-reply success: an assistant reply appears in that conversation. Saving a connection or passing a probe alone does not prove generation. Complete the first-chat guide.

If connection or generation fails

API disabled or unreachable? Check the listener and route from your device with the administrator. Access denied? Confirm the endpoint and Agent token, then retry explicitly or cancel. Browser rejected it? Check HTTPS trust and the exact CORS origin, not a wildcard. Operation unavailable? Ask for the exact supported Agent capability; there is no management fallback. Connected without a reply? Check the configured provider/model and credits.

Troubleshoot safely or repair a saved connection. Keep drafts and working connections; Wing does not silently replay requests. Never post credentials, private endpoints or conversations in an issue.

A few practical answers

Before you connect

01

I use the Hermes CLI. Is that enough?

Not by itself. Enable Agent's authenticated HTTP API and configure a provider/model. Wing uses the Agent token, not your provider key. First-chat guide.

02

Browser or native client?

The browser can preview the connection form without an Agent. Chat needs trusted HTTPS and an explicit allowed Wing CORS origin. Browser SSH and OAuth are unsupported. Native Android/Linux clients require a source build; full-app SSH authentication remains unverified.

03

Does Agent keep running when I leave?

If Agent runs on your computer, that computer must stay on and reachable. Closing Wing does not move Agent onto your phone. Android's manual Termux path does not guarantee background survival. Notifications and full away/return recovery remain unverified. Same-phone limits.
